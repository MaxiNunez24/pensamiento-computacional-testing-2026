    🔭 Adelanto: el proyecto que vamos a construir

    Acceso anticipado

    Esto es un adelanto de lo que viene en la segunda mitad del año. Todavía no hace falta entender cómo está hecho: mirálo, tocálo y hacete una idea de a dónde vamos. 🚀

    Durante el resto del curso vamos a construir un sistema de asistencias real para el CFP 401. No un ejercicio: el sistema que va a reemplazar la planilla que hoy se completa a mano.

    Se abre en el navegador, no hay que instalar nada. Cargá alumnos, pasá lista, mirá la planilla.

    🚀 Abrir el prototipo

    🗺️ El mapa del proyecto

    Antes de programar nada hay que decidir en qué partes se divide el sistema. Esa página es navegable: se toca cada pieza y muestra qué hace, quién la usa, con qué se construye y un boceto de cómo se vería.

    🗺️ Ver el proyecto por partes

    ¿Qué es lo que estoy viendo?

    Un prototipo: una maqueta que funciona de verdad, hecha para mostrarles a los preceptores y a la dirección cómo va a ser el sistema antes de construirlo.

    Eso es una práctica real de la industria y vale la pena que la vean de cerca: es mucho más barato cambiar una maqueta que rehacer un sistema terminado.

    ¿Vamos a programar esto?

    No exactamente, y esta es la parte importante.

    El prototipo está hecho en HTML y JavaScript, que no son parte del curso. Lo que ustedes van a construir es el mismo sistema en Python, y en varias etapas:

    Etapa Qué se construye Qué se aprende
    1️⃣ El sistema por consola POO: clases, objetos, métodos
    2️⃣ Que guarde los datos Archivos y JSON
    3️⃣ Que tenga tests pytest sobre código propio
    4️⃣ Que sea una página web Flask
    5️⃣ Que esté en internet Base de datos, usuarios y puesta en producción

    La planilla que se imprime ya está resuelta: se les entrega hecha, como un molde. Lo que programan ustedes es lo que la llena — diccionarios, listas, bucles y f-strings. Todo cosas que ya saben. 🧠

    Miren la planilla

    Entren a Planilla oficial dentro del prototipo. Eso es, milímetro a milímetro, el formulario que el CFP entrega todos los meses al Ministerio.

    Que un programa genere ese papel exacto a partir de datos cargados es, en una sola imagen, para qué sirve programar. 🎯

    Los alumnos que aparecen son inventados

    El prototipo viene con datos de ejemplo ficticios. Cuando trabajemos con el sistema en clase también vamos a usar datos inventados: los datos personales de una persona real no se publican ni se comparten, aunque sea "solo para probar". Es la primera regla del oficio. 🔒

    Para imprimir

    Papel Oficio (Legal), orientación horizontal, escala 100%. No usen "Ajustar al área de impresión": recalcula los anchos y deforma las columnas.
