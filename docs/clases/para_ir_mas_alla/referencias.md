# 🔗 Referencias

Para seguir por tu cuenta. **Todo lo de esta página es gratis.**

## 🗺️ El mapa

### [roadmap.sh](https://roadmap.sh){ target=_blank }

Mapas de todo lo que abarca cada área de la programación: backend, frontend, Python, bases de
datos. No es una lista para aprender de punta a punta: es un **mapa**, para ubicarte y elegir un
camino. Sirve para ver lo grande que es esto, y para darte cuenta de que ya recorriste un pedazo.

## 🎁 Tres recursos de midudev

Los tres los hizo **[Miguel Ángel Durán, midudev](https://midu.dev){ target=_blank }**, que
comparte gratis una cantidad enorme de material para aprender a programar en castellano. Gracias.

### [aprendesql.dev](https://aprendesql.dev){ target=_blank } — aprender SQL

Veintitantas lecciones en castellano, desde el primer `SELECT` hasta subconsultas, con **un editor
de SQL en cada lección** para probar en el momento. Es lo que conviene usar para practicar las
consultas del sistema de asistencias.

### [alg0.dev](https://alg0.dev){ target=_blank } — los algoritmos, animados

Casi cincuenta algoritmos que se ejecutan paso a paso delante tuyo: ordenamiento, búsqueda,
grafos, y conceptos como la notación **Big O**. Con código en Python. Va de la mano con **Lógica y
eficiencia**: lo que ahí medimos, acá se ve moverse.

### [itsfree.dev](https://itsfree.dev){ target=_blank } — servicios con plan gratis

Un catálogo de servicios que tienen un plan gratis de verdad: hosting, bases de datos, envío de
mails. Te va a servir el día que quieras **publicar un proyecto propio** en internet.
