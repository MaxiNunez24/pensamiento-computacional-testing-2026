# 📚 Libros
Aquí encontrarás una selección de libros recomendados para profundizar en el aprendizaje de Python y el pensamiento computacional. Estos libros cubren desde conceptos básicos hasta temas más avanzados, y son ideales para complementar lo que hemos visto en clase.

## [🔗 Enlace a Google Drive donde se encuentran los libros](https://drive.google.com/drive/folders/1V8d9SM6shxNL4WSmYy7kAcvkuvALs2ZL?usp=sharing)

---

## 📗​ Think Python - Allen B. Downey
Este libro es una excelente introducción a la programación con Python, ideal para principiantes. Cubre los fundamentos del pensamiento computacional y la programación de manera clara y accesible, con muchos ejemplos prácticos.

### [🔗 Enlace al libro](https://drive.google.com/file/d/1Nlse1GdF1y3wS9mgYGXl59K9SZI-C7TQ/view?usp=drive_link)


---

## 📘 Python para Todos - Charles Severance
Este libro es una extensión del libro "Think Python" y se enfoca en enseñar Python a través de proyectos prácticos. Es ideal para aquellos que quieren aprender haciendo, con ejercicios y ejemplos que van desde lo básico hasta temas más avanzados.

### [🔗 Enlace al libro](https://drive.google.com/file/d/1JqXVn2dgadaEliLWaBVC_oBD-e1DC4_v/view?usp=drive_link)
