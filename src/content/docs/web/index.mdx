:::tip[Optativo, y para hacer]
No hace falta para el proyecto del curso. Es para quien quiera **hacer sus propias páginas**: un
catálogo, la página de un emprendimiento, un portfolio. Todos los ejercicios corren acá mismo y
**muestran la página mientras la escribís**.
:::

Una página web está hecha de tres cosas, y cada una tiene su lenguaje:

| | Lenguaje | Qué hace | En una casa sería… |
|---|---|---|---|
| 🧱 | **HTML** | Dice **qué hay**: un título, un párrafo, una foto, un botón | Las paredes y los muebles |
| 🎨 | **CSS** | Dice **cómo se ve**: colores, tamaños, dónde va cada cosa | La pintura y la decoración |
| ⚡ | **JavaScript** | Hace que **responda**: que al tocar algo, pase algo | La luz que se prende con el interruptor |

Y lo que ya sabés de Python sirve, y mucho: la lógica es la misma, y con Python podés **armar las
páginas solas a partir de los datos**.
