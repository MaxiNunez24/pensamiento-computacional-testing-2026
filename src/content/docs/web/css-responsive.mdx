## El problema

Mandaste el link de tu catálogo por WhatsApp. **¿Desde dónde lo abren?** Desde el celular, casi
todos. Y una página pensada para la pantalla de la compu, en un celular, es una pesadilla: letra
diminuta, hay que hacer zoom, las fotos se salen del costado.

Una página **responsive** (que "responde" al tamaño) se ve bien en cualquier pantalla. No son dos
páginas: es **una sola**, con reglas que cambian según el ancho.

## La línea que no puede faltar

Antes de cualquier CSS, esto va en el `<head>` de toda página:

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

Sin ella, el celular **simula ser una pantalla de compu** de unos 980 píxeles y achica todo para que
entre: la letra queda diminuta, por más CSS que le pongas. Con ella, le decís *"usá el ancho real del
celular"*. Es la primera causa de "mi página se ve chiquita en el celular".

## Media queries: reglas que dependen del ancho

Una **media query** es un `if` de CSS: las reglas de adentro valen **solo si** se cumple la
condición.

```css
.catalogo {
  display: grid;
  grid-template-columns: 1fr;          /* en el celular: una columna */
}

@media (min-width: 600px) {
  .catalogo {
    grid-template-columns: repeat(3, 1fr);   /* desde 600px de ancho: tres */
  }
}
```

`min-width: 600px` quiere decir **"si la pantalla mide 600 o más"**. Fijate el orden: primero las
reglas para el celular, y después, con `min-width`, lo que **cambia** cuando hay más lugar. Se llama
**primero el celular** (*mobile first*), y es la forma recomendada, por dos motivos:

- la mayoría de las visitas son desde el celular, así que esa es la versión principal;
- es más fácil **agregar** cosas cuando hay lugar que **sacarlas** cuando no hay.

## Unidades que se adaptan

Los píxeles son fijos. Para que las cosas se acomoden, hay unidades **relativas**:

| Unidad | Es… | Para… |
|---|---|---|
| `%` | Un porcentaje **del contenedor** | Anchos: `width: 50%` |
| `rem` | Veces **la letra de la página** (normalmente 16px) | Tamaños de letra y espacios: `font-size: 1.5rem` |
| `vw` / `vh` | Un 1% del **ancho / alto de la pantalla** | Una portada que ocupe toda la pantalla: `height: 100vh` |

Usar `rem` para la letra tiene un beneficio enorme: si alguien que ve poco **agranda la letra** en su
celular, tu página se agranda con ella. Con `px`, no.

Y las imágenes: una foto de 1200px de ancho, en un celular de 360, **se sale**. Esta regla la
arregla para siempre:

```css
img {
  max-width: 100%;   /* como mucho, el ancho de su contenedor */
  height: auto;      /* y el alto, proporcional: que no se deforme */
}
```

## Variables de CSS

En una página, el mismo color aparece veinte veces: en el título, en los botones, en los precios. Si
un día cambia el color de la marca, hay que buscarlos todos. Con **variables**, se escribe una vez:

```css
:root {
  --principal: #2f4858;
  --fondo: #faf7f2;
}

h1      { color: var(--principal); }
.boton  { background: var(--principal); }
body    { background: var(--fondo); }
```

- Se definen con **dos guiones** adelante, y `:root` las hace valer **para toda la página**.
- Se usan con `var(--nombre)`.
- Cambiás `--principal` en un solo lugar, y cambia en todos.

Es la misma idea que una **variable de Python**: un nombre para un valor que se usa en muchos lados.

## Modo oscuro

Muchos usan el celular en **modo oscuro**. Tu página se puede enterar con una media query, y como
los colores están en variables, alcanza con **cambiar las variables**:

```css
:root {
  --fondo: #faf7f2;
  --texto: #2b2b2b;
}

@media (prefers-color-scheme: dark) {
  :root {
    --fondo: #1d2125;
    --texto: #e6e6e6;
  }
}

body {
  background: var(--fondo);
  color: var(--texto);
}
```

Todo lo que usa `var(--fondo)` y `var(--texto)` cambia solo. **Esa es la gran ventaja de las
variables**: el modo oscuro es redefinir dos o tres, no reescribir la página.

## Para llevar

- `<meta name="viewport" content="width=device-width, initial-scale=1">` en el `<head>`, siempre.
- **Media queries**: `@media (min-width: 600px) { ... }`, las reglas de adentro valen desde ese
  ancho. **Primero el celular**, después lo que cambia en la compu.
- Unidades relativas: `%` del contenedor, `rem` de la letra (respeta al que agranda la letra), `vw`/`vh`
  de la pantalla.
- `img { max-width: 100%; height: auto; }`: ninguna imagen se sale.
- **Variables**: `:root { --principal: #8a5a2b; }` y `var(--principal)`. Un cambio, y cambia todo.
- **Modo oscuro**: `@media (prefers-color-scheme: dark)` y redefinir las variables.
