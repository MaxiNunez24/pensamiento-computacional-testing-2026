:::tip[Antes de empezar]
Esta clase da por sabido **Python**: variables, `if`, `for`, funciones, listas y diccionarios. Si
eso lo tenés, JavaScript te va a resultar conocido. En estos ejercicios no hay página: lo que
importa es **la consola**, que es el `print` de JavaScript.
:::

## El problema

Con HTML y CSS la página **se ve**, pero no **hace** nada: tocás un botón y no pasa nada. Para que
responda hace falta un programa, y el único lenguaje que entienden **todos los navegadores** es
JavaScript.

La buena noticia: **ya sabés programar**. Las ideas son las mismas —variables, condiciones, bucles,
funciones, listas—; lo que cambia es **cómo se escriben**. Esta clase es una traducción.

## La gran diferencia: llaves en vez de sangría

En Python, lo que está **adentro** de un `if` o un `def` lo marca la **sangría**. En JavaScript, lo
marcan las **llaves** `{ }`, y la condición va entre **paréntesis**:

<Tabs>
<TabItem label="🐍 Python">
```python
if edad >= 18:
    print("Mayor")
else:
    print("Menor")
```
</TabItem>
<TabItem label="⚡ JavaScript">
```js
if (edad >= 18) {
  console.log("Mayor");
} else {
  console.log("Menor");
}
```
</TabItem>
</Tabs>

La sangría en JavaScript **se usa igual**, para que se lea bien, pero al lenguaje le da lo mismo:
mandan las llaves. Y cada instrucción termina con **punto y coma**: no siempre es obligatorio, pero
se pone.

## El diccionario de traducción

| Python | JavaScript | Ojo con… |
|---|---|---|
| `print("hola")` | `console.log("hola")` | Sale en **la consola**, no en la página |
| `# comentario` | `// comentario` | Y `/* ... */` para varias líneas |
| `nombre = "Ana"` | `let nombre = "Ana";` | `let` la primera vez. Si no va a cambiar: `const` |
| `True` / `False` | `true` / `false` | En minúscula |
| `None` | `null` | Y también `undefined`: "todavía no tiene valor" |
| `and` / `or` / `not` | `&&` / `\|\|` / `!` | |
| `==` | **`===`** | Ver abajo |
| `f"Hola, {nombre}"` | `` `Hola, ${nombre}` `` | Con **comillas invertidas** y `$` |
| `len(lista)` | `lista.length` | Es una propiedad, sin paréntesis |
| `lista.append(x)` | `lista.push(x)` | |
| `def doble(n):` | `function doble(n) {` | |
| `elif` | `else if` | |

### `let` y `const`

En Python una variable aparece la primera vez que le das valor. En JavaScript se **declara**:

```js
let total = 0;        // va a cambiar
total = total + 100;  // ya declarada: sin let

const IVA = 0.21;     // no va a cambiar nunca
```

Usá **`const` siempre que puedas**, y `let` solo si la vas a reasignar. Si después tratás de
cambiar una `const`, JavaScript te avisa con un error: te protege de pisarla sin querer.

## El `===`, y por qué no `==`

JavaScript tiene dos formas de comparar, y una es una trampa:

```js
5 == "5"     // true   ← convierte el texto a número, y "son iguales"
5 === "5"    // false  ← distinto tipo: no son iguales
```

`==` trata de **convertir** antes de comparar, y da resultados que nadie espera (`0 == ""` es
`true`). **`===` compara de verdad**, como el `==` de Python. Usá siempre `===` (y `!==` para
"distinto").

## Funciones

<Tabs>
<TabItem label="🐍 Python">
```python
def precio_con_iva(precio):
    return precio * 1.21
```
</TabItem>
<TabItem label="⚡ JavaScript">
```js
function precioConIva(precio) {
  return precio * 1.21;
}
```
</TabItem>
</Tabs>

Igual que en Python: parámetros, `return`, y se llama con paréntesis. Lo único que cambia es la
costumbre de los nombres: en JavaScript se escribe **`precioConIva`** (cada palabra nueva con
mayúscula) en vez de `precio_con_iva`.

## Listas y bucles

Una lista de Python es un **array** en JavaScript. Se escribe igual, con corchetes, y se recorre con
un `for ... of`:

<Tabs>
<TabItem label="🐍 Python">
```python
precios = [4500, 7800, 3200]
precios.append(5900)

total = 0
for p in precios:
    total += p
print(len(precios), total)
```
</TabItem>
<TabItem label="⚡ JavaScript">
```js
const precios = [4500, 7800, 3200];
precios.push(5900);

let total = 0;
for (const p of precios) {
  total += p;
}
console.log(precios.length, total);
```
</TabItem>
</Tabs>

:::caution[`of`, no `in`]
JavaScript también tiene `for (const x in lista)`, y **no hace lo que esperás**: recorre las
**posiciones** (`"0"`, `"1"`, `"2"`), no los elementos. El que equivale al `for` de Python es
**`for ... of`**.
:::

(Y sí: `precios` es `const` aunque le hagamos `push`. `const` quiere decir que la variable no pasa a
ser **otra** lista; la lista misma puede cambiar por dentro.)

## Diccionarios: objetos

Un diccionario de Python es un **objeto** en JavaScript. Las claves van **sin comillas**, y se lee
el valor con un **punto**:

<Tabs>
<TabItem label="🐍 Python">
```python
producto = {"nombre": "Mate", "precio": 7800}
print(producto["nombre"])
producto["precio"] = 8000
```
</TabItem>
<TabItem label="⚡ JavaScript">
```js
const producto = { nombre: "Mate", precio: 7800 };
console.log(producto.nombre);
producto.precio = 8000;
```
</TabItem>
</Tabs>

`producto["nombre"]` también funciona, como en Python; el punto es más corto y es lo que vas a ver
en todos lados.

## Para llevar

- **Llaves en vez de sangría**, condiciones entre paréntesis, `;` al final.
- `console.log` es el `print`. `let` para lo que cambia, **`const` para lo que no**.
- **`===` siempre**, nunca `==`. `true`, `false`, `null` en minúscula. `&&`, `||`, `!`.
- Template strings: `` `Hola, ${nombre}` ``, con comillas invertidas.
- `function nombre(params) { return ...; }`, y los nombres en `camelCase`.
- Arrays: `[1, 2]`, `.push()`, `.length`, y se recorren con **`for (const x of lista)`**.
- Objetos: `{ clave: valor }`, y se lee con `objeto.clave`.
