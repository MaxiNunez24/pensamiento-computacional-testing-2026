## El problema

Con títulos y párrafos se puede escribir un cuento, pero no una página de verdad. Cualquier página
que mires tiene **listas** (el menú, los ingredientes, los pasos), **links** que llevan a otra
parte, e **imágenes**. Con eso, ya podés armar la página de un emprendimiento.

## Listas

Hay dos, según si **el orden importa**:

| | Etiqueta | Se ve | Para… |
|---|---|---|---|
| Sin orden | `<ul>` (*unordered list*) | con viñetas • | Los ingredientes, lo que ofrece un local |
| Numerada | `<ol>` (*ordered list*) | 1. 2. 3. | Los pasos de una receta, un ranking |

Y adentro, **cada elemento** va en un `<li>` (*list item*), en las dos:

```html
<ul>
  <li>Yerba</li>
  <li>Azúcar</li>
</ul>

<ol>
  <li>Calentar el agua, sin que hierva</li>
  <li>Cebar</li>
</ol>
```

Es la misma idea que una **lista de Python**: una caja con elementos adentro, en orden. Solo que acá
`<ul>` u `<ol>` dicen además cómo se muestra.

## Links

Un link es la etiqueta `<a>` (*anchor*, ancla). **Adónde lleva** va en el atributo `href`, y lo que
queda adentro es **el texto que se ve** y se toca:

```html
<a href="https://www.argentina.gob.ar">Ir a Argentina.gob.ar</a>
```

Hay tres clases de dirección:

| `href` | Lleva a… |
|---|---|
| `https://www.algo.com/pagina` | **Otra página de internet**: la dirección entera |
| `contacto.html` | **Otra página tuya**, en la misma carpeta |
| `#horarios` | **Otra parte de esta misma página**: la que tenga `id="horarios"` |

El último sirve para los menús que bajan hasta una sección. El destino lleva un **`id`**, un nombre
que no se puede repetir en la página:

```html
<a href="#horarios">Ver los horarios</a>
...
<h2 id="horarios">Horarios</h2>
```

Y si querés que el link se abra **en otra pestaña**, sin que la persona se vaya de tu página:

```html
<a href="https://wa.me/5492215550000" target="_blank">Escribinos</a>
```

## Imágenes

Una imagen es la etiqueta `<img>`, y es de las que **no se cierran**: no tiene contenido, solo
atributos.

```html
<img src="mate.jpg" alt="Un mate de calabaza con bombilla de alpaca">
```

| Atributo | Qué es |
|---|---|
| `src` | **Qué archivo mostrar**: una dirección, como en los links |
| `alt` | **La descripción de la imagen**, en palabras |

El `alt` **no es opcional**, aunque la página se vea igual sin él. Lo leen:

- los **lectores de pantalla**, que le dicen a una persona ciega qué hay en la imagen;
- el navegador, que lo muestra **cuando la imagen no carga** (una conexión lenta, un nombre mal escrito);
- los buscadores, para saber de qué es la foto.

Un buen `alt` describe **lo que importa** de la imagen, como se lo contarías a alguien por teléfono.
`alt="foto"` o `alt="imagen1"` no le sirven a nadie.

## Énfasis: negrita e itálica

Para marcar que algo **importa**, `<strong>`; para el *énfasis* al decirlo, `<em>`:

```html
<p>El curso es <strong>gratuito</strong>, y <em>no</em> hace falta saber programar.</p>
```

Se ven en negrita y en itálica, pero lo que dicen es **para qué** están: un lector de pantalla
cambia el tono de voz. Si solo querés que algo se vea en negrita porque queda lindo, eso es trabajo
de CSS.

  html={`<h1>Inscripciones abiertas</h1>

## Para llevar

- **Listas**: `<ul>` con viñetas, `<ol>` numerada, y cada cosa en un `<li>`.
- **Links**: `<a href="...">texto</a>`. Una dirección entera, otra página tuya, o `#id` para otra
  parte de la misma. `target="_blank"` abre otra pestaña.
- `id="nombre"` le pone un nombre único a un elemento: es el destino de los links con `#`.
- **Imágenes**: `<img src="..." alt="...">`, sin cierre. **El `alt` no es opcional.**
- `<strong>` para lo importante y `<em>` para el énfasis: dicen **por qué**, no solo cómo se ve.
