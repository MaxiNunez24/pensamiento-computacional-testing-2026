:::note[¿Por qué Archivos y JSON están acá, si antes eran clases del curso?]
Porque el sistema de asistencias guarda los datos en una **base de datos** desde el principio.
Pasar primero por archivos era un desvío que después había que deshacer.

Lo único de archivos que el proyecto sí necesita —**leer la planilla del formulario de
inscripción**, que es un CSV— lo vemos con <a href={b + 'clases/bot-siges/'}>el bot del SiGeS</a>,
justo cuando hace falta.
:::
