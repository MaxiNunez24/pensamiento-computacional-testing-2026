## El problema

El sistema de asistencias por consola anda, pero pensá en quien lo va a usar: una preceptora que
nunca vio una terminal, frente a un cursor que parpadea esperando que escriba un número de menú.

Lo que esa persona espera es **una ventana**: un lugar donde escribir el DNI, un botón que diga
**Registrar** y un cartel que conteste. Eso se puede hacer con lo que ya sabés, más una sola
librería: **Tkinter**.

:::tip[Tkinter ya está en tu compu]
Viene **incluido con Python**: no hay que instalar nada con `pip` ni armar un entorno virtual. Si
tenés Python y VS Code, ya está todo.

## Tu primera ventana

Copiá esto en `ventana.py` y tocá el ▶:

```python
import tkinter as tk

ventana = tk.Tk()
ventana.title("Mi primera ventana")
ventana.geometry("400x200")

ventana.mainloop()
```

Aparece una ventana vacía de 400 de ancho por 200 de alto, con tu título arriba. Línea por línea:

| Línea | Qué hace |
|---|---|
| `import tkinter as tk` | Trae la librería, y le da el apodo `tk` para escribir menos |
| `ventana = tk.Tk()` | Crea la ventana. Es un **objeto**, como los de POO |
| `ventana.title(...)` | El texto de la barra de arriba |
| `ventana.geometry("400x200")` | El tamaño: ancho **x** alto, en píxeles |
| `ventana.mainloop()` | Deja la ventana abierta, esperando que hagas algo |

### Qué hace `mainloop()`

Un programa de consola corre de arriba abajo y termina. Una ventana no puede hacer eso: tiene que
quedarse **esperando** a que toques algo. `mainloop()` es un bucle que hace justamente eso: se
queda mirando qué toca el usuario, y no termina hasta que cerrás la ventana.

Se parece a `input()`, que también frena el programa hasta que escribís algo. La diferencia es que
`input()` espera **una** respuesta, y `mainloop()` espera **todo el tiempo**, cualquier cosa.

## Textos y botones

Las cosas que van adentro de una ventana se llaman **widgets**: un texto, un botón, una caja para
escribir. Cada uno es un objeto, y se crea diciéndole **en qué ventana va**:

```python
import tkinter as tk

ventana = tk.Tk()
ventana.title("Saludo")
ventana.geometry("400x200")

mensaje = tk.Label(ventana, text="Todavía no tocaste nada", font=("Arial", 14))
mensaje.pack(pady=20)

boton = tk.Button(ventana, text="Saludar")
boton.pack()

ventana.mainloop()
```

- **`tk.Label`** es un texto que el usuario lee pero no puede cambiar.
- **`tk.Button`** es un botón.
- **`.pack()`** lo pone en la ventana, uno abajo del otro. Si te olvidás del `.pack()`, el widget
  existe pero **no se ve**.
- `pady=20` le deja 20 píxeles de aire arriba y abajo.

Tocá el botón: no pasa nada. Todavía no le dijimos **qué hacer**.

## Que el botón haga algo

Lo que hace un botón es una **función**. Primero la escribís, y después se la das al botón con
`command`:

```python
import tkinter as tk


def saludar():
    mensaje.config(text="¡Hola! Tocaste el botón.")


ventana = tk.Tk()
ventana.title("Saludo")
ventana.geometry("400x200")

mensaje = tk.Label(ventana, text="Todavía no tocaste nada", font=("Arial", 14))
mensaje.pack(pady=20)

boton = tk.Button(ventana, text="Saludar", command=saludar)
boton.pack()

ventana.mainloop()
```

`mensaje.config(text=...)` le cambia el texto a un Label que ya existe. Es como cambiarle un
atributo a un objeto.

:::tip[Esto es nuevo: el programa espera a que lo llames]
Hasta ahora vos decidías **cuándo** se ejecutaba cada función, llamándola en tu código. Con una
ventana, la que decide es **la persona que toca el botón**. Vos solo dejás la función preparada y
le avisás al botón cuál es. A esto se le dice **programación por eventos**: cada clic es un evento.

## Leer lo que escriben

Para que el usuario escriba, está **`tk.Entry`**: una caja de una línea. Lo que escribió se lee con
**`.get()`**, que siempre devuelve **texto**, como `input()`:

```python
import tkinter as tk


def saludar():
    nombre = entrada.get()
    mensaje.config(text=f"¡Hola, {nombre}!")


ventana = tk.Tk()
ventana.title("Saludo")
ventana.geometry("400x220")

tk.Label(ventana, text="¿Cómo te llamás?").pack(pady=10)

entrada = tk.Entry(ventana, font=("Arial", 14))
entrada.pack()

tk.Button(ventana, text="Saludar", command=saludar).pack(pady=10)

mensaje = tk.Label(ventana, text="", font=("Arial", 14))
mensaje.pack()

ventana.mainloop()
```

El primer Label y el botón no se guardan en una variable: se crean y se ponen en la misma línea
con `.pack()`. Se puede hacer cuando no los vas a volver a tocar. A `entrada` y a `mensaje` sí los
necesitamos después, adentro de `saludar`, y por eso tienen nombre.

## Números, errores y carteles

Ahora algo del proyecto: el **porcentaje de asistencia**. Se escriben las clases dadas y las
faltas, y la ventana dice si llega al 85 %.

Como `.get()` devuelve texto, hay que pasarlo a número con `int()`. Y si escriben `diez` en vez
de `10`, `int()` tira un `ValueError`: lo atrapamos con `try` / `except`, como en la clase de
Excepciones, y avisamos con un **cartel** (`messagebox`):

```python
import tkinter as tk
from tkinter import messagebox


def calcular():
    try:
        clases = int(entrada_clases.get())
        faltas = int(entrada_faltas.get())
    except ValueError:
        messagebox.showerror("Dato inválido", "Escribí solo números enteros.")
        return

    if clases <= 0:
        messagebox.showerror("Dato inválido", "Tiene que haber al menos una clase.")
        return

    porcentaje = round((clases - faltas) * 100 / clases)
    if porcentaje >= 85:
        resultado.config(text=f"{porcentaje} % — Regular", fg="green")
    else:
        resultado.config(text=f"{porcentaje} % — Le falta asistencia", fg="red")


ventana = tk.Tk()
ventana.title("Asistencia")

tk.Label(ventana, text="Clases dadas:").grid(row=0, column=0, padx=10, pady=10)
entrada_clases = tk.Entry(ventana)
entrada_clases.grid(row=0, column=1, padx=10)

tk.Label(ventana, text="Faltas:").grid(row=1, column=0, padx=10, pady=10)
entrada_faltas = tk.Entry(ventana)
entrada_faltas.grid(row=1, column=1, padx=10)

tk.Button(ventana, text="Calcular", command=calcular).grid(row=2, column=0, columnspan=2, pady=10)

resultado = tk.Label(ventana, text="", font=("Arial", 16))
resultado.grid(row=3, column=0, columnspan=2, pady=10)

ventana.mainloop()
```

Tres cosas nuevas:

- **`messagebox.showerror(título, mensaje)`** abre un cartel de error con un botón **OK**. Hay
  también `showinfo` (información) y `showwarning` (advertencia). Se importa aparte, con
  `from tkinter import messagebox`.
- **`return`** solo, sin nada, corta la función ahí. Si el dato estaba mal, no tiene sentido
  seguir calculando.
- **`.grid()`** en vez de `.pack()`: acomoda los widgets en una **grilla** de filas y columnas,
  como una planilla. `row` es la fila, `column` la columna (las dos empiezan en 0), y
  `columnspan=2` hace que el botón ocupe las dos columnas. En una misma ventana usá **o `pack`
  o `grid`**, no los dos mezclados.

`fg` es el color de las letras (*foreground*): `"green"`, `"red"`, `"blue"`… o un código como
`"#ff4d6d"`, como en CSS.

## Ordenarlo con una clase

Cuando la ventana crece, tantas variables sueltas se vuelven un lío. Lo que ya sabés de **POO**
lo ordena: la ventana es un objeto, los widgets son sus **atributos** y lo que hacen los botones
son sus **métodos**. Por ejemplo, un contador de clics:

```python
import tkinter as tk


class Contador:
    def __init__(self, ventana):
        self.cantidad = 0
        self.etiqueta = tk.Label(ventana, text="0", font=("Arial", 40))
        self.etiqueta.pack(pady=20)
        tk.Button(ventana, text="Sumar uno", command=self.sumar).pack()

    def sumar(self):
        self.cantidad = self.cantidad + 1
        self.etiqueta.config(text=str(self.cantidad))


ventana = tk.Tk()
ventana.title("Contador")
ventana.geometry("300x220")
Contador(ventana)
ventana.mainloop()
```

- `command=self.sumar`: el método del objeto, otra vez **sin paréntesis**.
- `self.cantidad` guarda la cuenta entre un clic y el siguiente. Sin la clase, tendría que ser
  una variable de afuera de la función, y Python no te deja cambiarla desde adentro sin un truco
  extra (`global`). El objeto la guarda sin vueltas.

## Para llevar

```python
import tkinter as tk
from tkinter import messagebox

ventana = tk.Tk()                         # la ventana
ventana.title("Título")
ventana.geometry("400x300")               # ancho x alto

texto = tk.Label(ventana, text="Hola")    # un texto
caja = tk.Entry(ventana)                  # una caja para escribir
boton = tk.Button(ventana, text="OK", command=una_funcion)   # sin paréntesis
lista = tk.Listbox(ventana)               # una lista

texto.pack()                              # uno abajo del otro…
caja.grid(row=0, column=1)                # …o en grilla (no los dos juntos)

caja.get()                                # lo que escribieron (siempre texto)
caja.delete(0, tk.END)                    # vaciar la caja
texto.config(text="Chau", fg="red")       # cambiar un widget que ya existe
lista.insert(tk.END, "Ana")               # agregar al final de la lista
messagebox.showerror("Título", "Mensaje") # también showinfo y showwarning

ventana.mainloop()                        # siempre al final
```

- Se hace en **VS Code**: la plataforma no puede abrir ventanas.
- Tu archivo **nunca** se llama `tkinter.py`.
- Sin `mainloop()` la ventana se cierra sola. Sin `.pack()` o `.grid()`, el widget no se ve.
- El botón recibe la función **sin paréntesis**: la llama él, cada vez que lo tocan.
