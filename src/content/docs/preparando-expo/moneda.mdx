## El problema

Una moneda en la pantalla. Antes de tirarla, elegís: **¿cara o cruz?** La tocás, **sube girando en
el aire, cae**, y recién ahí te dice si **ganaste o perdiste**.

Para hacerla hacen falta cuatro cosas, y cada una es una parte de esta clase:

1. **El azar**: que el programa elija cara o cruz sin que nadie lo sepa de antemano.
2. **El juego**: comparar lo que salió con lo que elegiste.
3. **La animación**: que suba, gire y caiga, con CSS.
4. **El tiempo**: que el resultado aparezca cuando la moneda **cae**, no cuando la tocás.

Y una quinta, para la Expo: **cargar la moneda**, para elegir qué tan seguido gana quien juega si
alguna vez la usamos para sortear un premio.

## El azar: Math.random()

En Python, para algo al azar estaba `random.random()`: un número entre 0 y 1. En JavaScript es lo
mismo, sin `import`:

```js
console.log(Math.random());   // 0.7310582...
console.log(Math.random());   // 0.0912345...  (cada vez, otro)
```

Da un número **desde 0 hasta casi 1** (nunca llega a 1), y cualquiera tiene la misma chance. Con eso
se arma una moneda: la mitad de las veces el número es menor que `0.5`.

```js
function tirar() {
    if (Math.random() < 0.5) {
        return "cara";
    }
    return "cruz";
}
```

## La moneda cargada

En `Math.random() < 0.5`, el `0.5` es **la probabilidad de que salga cara**: la mitad de las veces.
Si lo cambiás por `0.8`, el número es menor que 0.8 **ocho de cada diez veces**, y sale cara mucho
más seguido. Es una moneda cargada.

Pero para un sorteo, lo que importa no es si sale cara o cruz: es **si gana quien juega**. Cargarla
para la cara no sirve de nada si la persona eligió cruz. Entonces `tirar` tiene que saber **qué
eligió**, y el número pasa a ser **la probabilidad de que gane**: si el azar cae debajo, sale lo que
eligió; si no, lo otro.

Conviene que ese número sea un **parámetro**, con un valor por defecto para la moneda pareja. Igual
que en Python:

```python
def tirar(elegido, prob_ganar=0.5):
    ...
```

```js
function tirar(elegido, probGanar = 0.5) {
    // ...
}
```

### ¿Cómo se prueba una moneda cargada?

No alcanza con tirarla una vez: puede ganar de casualidad. **Se tira muchas veces y se cuenta.**
Si la cargaste al 80%, de 4000 tiradas tiene que ganar unas 3200. Así la prueba el test del próximo
ejercicio: es un **test estadístico**, y es como se prueba de verdad cualquier cosa al azar.

## El juego: ganaste o perdiste

Ahora el juego en sí: dos botones para elegir, y un mensaje que diga qué salió y si acertaste.

### ¿Cómo se prueba algo que sale al azar?

Si el resultado cambia cada vez, ¿cómo sabe el test qué mensaje esperar? **Hace trampa, a
propósito:** antes de tocar un botón, **reemplaza `Math.random`** por una función que devuelve
siempre lo mismo.

```js
Math.random = function () { return 0.3; };   // de acá en más, "el azar" da 0.3
// 0.3 es menor que 0.5: con la moneda pareja, gana seguro
```

Así el test sabe que ganás, y puede revisar que diga *"Salió cara: ¡ganaste!"* si elegiste cara. Con
`0.9` sabe que perdés. Fijar el azar para poder probar es algo que se hace siempre en testing. Funciona **solo si tu
programa usa `Math.random()`** para sortear: por eso el `tirar` de antes.

## La animación: que suba, gire y caiga

Hasta acá el resultado aparece de golpe. Para que la moneda **vuele**, CSS tiene dos herramientas.

**`transform`** mueve, gira o agranda algo, sin correr lo que está alrededor:

```css
.moneda {
    transform: translateY(-120px);   /* 120px para ARRIBA (en pantalla, arriba es negativo) */
    transform: rotateY(180deg);      /* media vuelta, como una puerta que gira */
    transform: translateY(-120px) rotateY(180deg);   /* las dos cosas a la vez */
}
```

**`@keyframes`** es una animación con nombre: dice cómo está en distintos momentos, y el navegador
dibuja todo lo del medio.

```css
@keyframes girar {
    0% {
        transform: translateY(0) rotateY(0);               /* empieza abajo, quieta */
    }
    50% {
        transform: translateY(-120px) rotateY(900deg);     /* arriba de todo, dos vueltas y media */
    }
    100% {
        transform: translateY(0) rotateY(1800deg);         /* vuelve abajo: cinco vueltas */
    }
}

.moneda.girando {
    animation: girar 1.2s;   /* el nombre y cuánto dura */
}
```

Fijate que la animación se la pone **una clase**: la moneda gira cuando tiene la clase `girando`. Y
agregarle una clase a algo ya sabés hacerlo desde JavaScript.

:::note[Que caiga como una moneda de verdad]
Una moneda sube rápido y frena arriba, y baja lento y acelera. Eso es `animation-timing-function`:
`ease-out` (frena al final) para la subida y `ease-in` (acelera) para la bajada. Se puede poner en
cada momento del `@keyframes`, como en la moneda completa de más abajo.
:::

## El tiempo: el resultado, cuando cae

Si el resultado aparece apenas tocás el botón, la moneda todavía está en el aire y ya sabés qué
salió: se arruina el suspenso. Hay que esperar a que **termine la animación**.

El navegador avisa cuando una animación termina, con un evento: **`animationend`**. Se escucha como
un clic:

```js
moneda.addEventListener("animationend", function () {
    // la moneda ya cayó
});
```

Entonces el juego queda en dos tiempos:

1. **Al tocar el botón**: se sortea qué sale y se le pone la clase que la hace girar. Nada más.
2. **En `animationend`**: se le saca la clase (si no, la próxima vez no vuelve a girar, porque ya
   la tiene) y **recién ahí** se muestra el resultado.

## La moneda completa

Una moneda de verdad tiene **dos caras**, y cae mostrando la que salió. Eso ya es CSS en 3D, y viene
hecho: está en el `estilos.css` del [proyecto para bajar](#la-moneda-en-tu-página), con un
comentario en cada regla por si te da curiosidad. Para usarlo alcanza con saber **tres clases**:

| Clase en `.moneda` | Qué hace |
|---|---|
| `gira-cara` | Sube girando y cae mostrando la **cara** |
| `gira-cruz` | Sube girando y cae mostrando la **cruz** |
| `muestra-cruz` | Quieta, mostrando la cruz (sin ella, muestra la cara) |

Y la regla de oro del ejercicio anterior: **se sortea al tocar, y se muestra al caer**.

## Para la Expo: el panel secreto

Si en la Expo usamos la moneda para sortear un premio, quizás queramos que **se gane más (o menos)
seguido**. Para eso, un **panel secreto**: una barra para elegir la probabilidad de ganar, que
aparece y desaparece con una tecla, así el público no la ve.

Dos cosas nuevas, chiquitas:

- **Una tecla** es el evento `keydown`, y se escucha en todo el documento. Cuál fue, está en
  `evento.key`:

  ```js
  document.addEventListener("keydown", function (evento) {
      if (evento.key === "p" || evento.key === "P") {
          // apretaron la P (minúscula o mayúscula)
      }
  });
  ```

- **Una barra** es un `<input type="range">`. Su valor está en `.value`, como cualquier campo, y
  avisa con el evento `input` cada vez que se mueve. Ojo: va de **0 a 100**, y `tirar` quiere un
  número de **0 a 1**.

  ```html
  <input id="prob" type="range" min="0" max="100" value="50">
  ```

### Un dado

Para un número entero al azar se multiplica y se redondea para abajo, con `Math.floor`:

```js
Math.random() * 6                     // de 0 hasta casi 6: 0.3, 2.7, 5.9...
Math.floor(Math.random() * 6)         // un entero de 0 a 5
Math.floor(Math.random() * 6) + 1     // un entero de 1 a 6, como un dado
```

Es lo mismo que en Python hacía `random.randint(1, 6)`.

## Para llevar

- **`Math.random()`** da un número de 0 a casi 1. `Math.random() < p` es verdad con probabilidad
  `p`: así se carga una moneda. Para un sorteo, `p` es la probabilidad de **ganar**: sale lo que
  eligió, o lo otro.
- Algo al azar **se prueba tirándolo muchas veces** (un test estadístico), o **fijando el azar**:
  reemplazando `Math.random` por una función que devuelve siempre lo mismo.
- **`transform`** mueve (`translateY`) y gira (`rotateY`). **`@keyframes`** dice cómo está en cada
  momento, y una **clase** con `animation` la pone en marcha.
- El evento **`animationend`** avisa cuando la animación terminó: **se sortea al tocar y se muestra
  al caer**.
- Una **tecla** es `keydown` (cuál, en `evento.key`); una **barra** es `<input type="range">`.
