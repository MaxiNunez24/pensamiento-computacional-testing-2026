## Qué vamos a mostrar

| | Qué | Quién lo hace |
|---|---|---|
| 🛍️ | **La vidriera**: los catálogos del curso, cada uno con su **QR** para abrirlo en el celular | Cada uno publica el suyo; la página que los junta la arma Python |
| 🎮 | **Jugá**: juegos para jugar en el celular de quien pasa. El primero, **cara o cruz** | La idea de la moneda es de un compañero; cada uno puede sumar el suyo |
| 🧩 | **Cómo se planifica un sistema**: el Sistema de Gestión de Alumnos, desde el problema hasta cómo se va a ver | Lo presentamos entre todos, cada uno una parte |

Todo va a estar en **[una página propia para la Expo](../expo/)**, pensada para el celular de
quien pasa, y con una versión para la pantalla grande: **[la animación del sistema en
loop](../expo/pantalla/)**. Cuando tu catálogo y tu juego estén publicados, aparecen ahí.

### Y si llegamos: un catálogo para cualquiera del CFP

La idea es que **cualquier estudiante del CFP** con un emprendimiento pueda tener su catálogo:
completa un formulario, alguien lo aprueba, y se publica solo. Si llegamos antes de la Expo, se va
a poder completar el formulario ahí mismo; si no, lo terminamos después.

## Lo que tiene que tener listo cada uno

- [ ] **Tu catálogo publicado** en GitHub Pages, con tus productos y tus fotos.
- [ ] **Los datos para la vidriera**, para pasarle al profe: nombre del emprendimiento, rubro (dos o
      tres palabras), un emoji y el link.
- [ ] **Tu QR probado**: escanealo con el celular y fijate que abra tu catálogo.
- [ ] **Un juego publicado** (la moneda, u otro tuyo), si querés sumarlo a la sección de juegos.
- [ ] **Tu parte de la presentación** del sistema: la vamos a repartir en clase.
