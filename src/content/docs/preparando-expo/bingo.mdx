## Del set de Python al Set de JavaScript

El cartón eran números **sin repetir**, y para eso estaba el `set`. JavaScript tiene lo mismo, con
otros nombres:

| Python | JavaScript | Para qué |
|---|---|---|
| `numeros = set()` | `const numeros = new Set();` | Un conjunto vacío |
| `numeros.add(7)` | `numeros.add(7);` | Agregar (si ya estaba, no pasa nada) |
| `7 in numeros` | `numeros.has(7)` | ¿Está? |
| `len(numeros)` | `numeros.size` | Cuántos hay |
| `sorted(numeros)` | `[...numeros].sort((a, b) => a - b)` | Pasarlo a lista, ordenada |

Y el número al azar, que en Python era `random.randint(1, 30)`:

```js
Math.floor(Math.random() * 30) + 1   // un entero entre 1 y 30
```

`Math.random()` da desde 0 hasta casi 1; por 30, desde 0 hasta casi 30; `Math.floor` le saca los
decimales (de 0 a 29), y el `+ 1` lo corre a 1 a 30.

## ¿Ganó?

En Python se ganaba cuando **todos** los números del cartón ya habían salido: `carton.issubset(sorteados)`,
o `all(n in sorteados for n in carton)`. En JavaScript, las listas tienen `every`: le pasás una
pregunta para **cada** elemento, y da `true` si la respuesta es sí para todos.

```js
[4, 8, 12].every((n) => n % 2 === 0)   // true: todos son pares
[4, 7, 12].every((n) => n % 2 === 0)   // false: el 7 no
```

Y para preguntar si un número está en una lista, `includes`, que es el `in` de Python:

```js
[5, 9, 22].includes(9)   // true
```

## ¿De qué tamaño el cartón?

El Bingo de la clase tenía cartones de **15 números del 1 al 90**, como el de verdad. Para la Expo
eso no sirve, y no por gusto: **lo simulamos**. Se jugaron miles de partidas en la compu, con una
bolilla cada 6 segundos, para ver cuánto tardaba alguien en ganar:

| Cartón | Jugadores | Bolillas hasta el primer Bingo | Tiempo |
|---|---|---|---|
| 15 de 90 | 15 | unas 75 | **7 minutos y medio** |
| 6 de 30 | 15 | unas 20 | 2 minutos |
| 5 de 25 | 5 | unas 18 | casi 2 minutos |
| 7 de 35 | 40 | unas 22 | 2 minutos |

En un stand, nadie se queda siete minutos parado. Y además: **con más gente, alguien completa antes**.
Por eso el cartón se elige según cuántos juegan, para que la partida dure siempre unos dos minutos.

## El cartón en la pantalla (optativo)

Lo último: que el cartón **se vea**, con los números que ya salieron marcados. Es lo que muestra el
celular de quien juega.
