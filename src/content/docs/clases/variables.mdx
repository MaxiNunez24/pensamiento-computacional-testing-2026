## El problema

Mirá este precio repetido por todos lados:

```python
print("El café sale 1500")
print("Dos cafés salen", 1500 * 2)
print("Con 10% de descuento:", 1500 * 0.9)
```

Si mañana el café aumenta, tenés que cazar **cada** `1500` y cambiarlo. Si te olvidás uno, el programa
queda mintiendo y no te avisa.

Una **variable** es un nombre para un valor. Lo escribís una vez y lo usás donde quieras:

```python
precio_cafe = 1500

print("El café sale", precio_cafe)
print("Dos cafés salen", precio_cafe * 2)
print("Con 10% de descuento:", precio_cafe * 0.9)
```

Ahora el precio vive en **un solo lugar**. Eso es lo que ganás: no repetir, y tener un lugar único
donde cambiar las cosas.

## Cómo se crea

```python
nombre_de_la_variable = valor
```

El `=` **no** es "igual" como en matemática: es **"guardá esto acá"**. Se lee de derecha a izquierda.

```python
edad = 30        # guardá 30 en edad
edad = edad + 1  # tomá lo que hay en edad, sumale 1, y guardalo de nuevo en edad
```

Esa segunda línea en matemática sería absurda. En programación es de lo más común.

## Los cuatro tipos básicos

Todo valor en Python es de algún **tipo**. Al principio te alcanza con cuatro:

| Tipo | Qué guarda | Ejemplos |
|------|-----------|----------|
| `int` | Números enteros | `30`, `-5`, `0` |
| `float` | Números con decimales | `1.5`, `-0.75`, `3.0` |
| `str` | Texto (*string*) | `"hola"`, `"30"`, `""` |
| `bool` | Verdadero o falso | `True`, `False` |

Podés preguntarle a Python de qué tipo es algo con `type()`:

```python
print(type(30))        # <class 'int'>
print(type("30"))      # <class 'str'>
print(type(1.5))       # <class 'float'>
print(type(True))      # <class 'bool'>
```

## `"30"` no es `30`

Esta distinción causa la mitad de los errores del primer mes, así que vale la pena frenar acá.

```python
30 + 30       # 60      → dos números: los suma
"30" + "30"   # "3030"  → dos textos: los pega uno atrás del otro
"30" + 30     # 💥 TypeError
```

El `30` con comillas es el **dibujo** del número: sirve para mostrarlo, no para hacer cuentas.

Para pasar de uno a otro, se **convierte**:

```python
int("30")     # 30      texto → entero
str(30)       # "30"    entero → texto
float("1.5")  # 1.5     texto → decimal
```

:::caution[Convertir puede fallar]
```python
int("hola")   # 💥 ValueError: no hay ningún número ahí adentro
int("3.5")    # 💥 ValueError: eso es un decimal, no un entero
float("3.5")  # ✅ 3.5
```
:::

## Cómo nombrar variables

Las reglas que Python te obliga:

- Empiezan con letra o `_`, nunca con número.
- Sin espacios ni acentos ni guiones: `precio_cafe`, no `precio café` ni `precio-cafe`.
- Distingue mayúsculas: `edad` y `Edad` son **dos variables distintas**.

Y la regla que no te obliga pero importa más:

:::tip[El nombre es para la persona que lee]
```python
x = 1500        # ¿1500 qué?
precio_cafe = 1500   # ah, listo
```
En Python se estila `snake_case`: todo en minúscula, palabras separadas por `_`. El código se lee
muchas más veces de las que se escribe, y casi siempre lo lee tu yo de dentro de dos semanas.
:::

## Operadores

```python
7 + 2    # 9    suma
7 - 2    # 5    resta
7 * 2    # 14   multiplicación
7 / 2    # 3.5  división (siempre da float)
7 // 2   # 3    división entera (se queda con la parte entera)
7 % 2    # 1    resto de la división
7 ** 2   # 49   potencia
```

Los dos raros, `//` y `%`, son mucho más útiles de lo que parecen: `%` te dice si un número es
múltiplo de otro (si el resto es 0), y juntos sirven para partir cantidades.
