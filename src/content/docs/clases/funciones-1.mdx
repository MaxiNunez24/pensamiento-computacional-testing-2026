## El problema

Tenés que saludar a tres personas:

```python
print("¡Hola, Ana!")
print("¡Hola, Beto!")
print("¡Hola, Carla!")
```

Funciona... pero si mañana el saludo cambia a "¡Buenas, Ana!", tenés que tocar **las tres líneas**.
Y si fueran 100 personas, 100 líneas. Estás **repitiendo** la misma idea una y otra vez.

¿Y si pudieras guardar la idea de "saludar" en un solo lugar, ponerle nombre, y reusarla las veces
que quieras? Para eso existen las **funciones**.

## Qué es una función

Una función es un **bloque de código con nombre** que podés ejecutar (llamar) cuando quieras. Recibe
datos de entrada (**parámetros**) y puede devolver un resultado (**retorno**).

```python
def saludar(nombre):       # 'nombre' es el parámetro (la entrada)
    return f"¡Hola, {nombre}!"   # 'return' devuelve el resultado

mensaje = saludar("Ana")   # la llamamos con "Ana"
print(mensaje)             # ¡Hola, Ana!
```

Tres piezas clave:

- **`def`** + nombre + `(parámetros)` → así se **define**.
- **`return`** → el valor que la función **devuelve** a quien la llamó.
- **Llamarla**: `saludar("Ana")` ejecuta el bloque con `nombre = "Ana"`.

:::caution[`return` no es `print`]
`print` **muestra** algo en pantalla; `return` **devuelve** un valor para seguir usándolo. Una
función que solo hace `print` no te sirve para guardar el resultado en una variable.
:::

## Manos a la obra

:::note[Vas a ver `pass` en el código]
`pass` es un **marcador de lugar**: una línea que no hace nada. Está para que el código sea válido
mientras todavía no lo escribiste. **Borralo y poné tu solución** en su lugar.
:::

## Para llevar

- `def nombre(parametros):` define una función.
- `return` devuelve un valor (distinto de `print`).
- Definís una vez, la llamás todas las veces que quieras → **menos repetición, menos errores**.
