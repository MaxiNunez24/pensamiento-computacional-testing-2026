## El problema

Contar del 1 al 5 se puede hacer así:

```python
print(1)
print(2)
print(3)
print(4)
print(5)
```

¿Y del 1 al 1000? No vas a escribir mil líneas. Y peor: si mañana hay que cambiar algo, hay que
cambiarlo mil veces.

Un **bucle** te deja escribir la instrucción **una vez** y decirle a Python cuántas veces repetirla.

## `while`: repetir mientras se cumpla algo

```python
numero = 1

while numero <= 5:
    print(numero)
    numero = numero + 1
```

Se lee literal: *"mientras `numero` sea menor o igual a 5, mostralo y sumale 1"*.

Un `while` tiene siempre tres partes, y si te falta alguna se rompe:

1. **Antes**: preparar la variable (`numero = 1`).
2. **La condición**: hasta cuándo seguir (`numero <= 5`).
3. **Adentro**: hacer algo **y acercarse al final** (`numero = numero + 1`).

:::caution[El bucle infinito]
Si te olvidás el paso 3, la condición nunca se vuelve falsa y el programa **no termina nunca**:

```python
numero = 1
while numero <= 5:
    print(numero)      # 💥 imprime 1 para siempre
```

Acá no pasa nada grave: a los 15 segundos la página corta la ejecución sola y te avisa. En tu compu
tendrías que frenarlo con `Ctrl + C`.
:::

## `for`: repetir una vez por cada elemento

Cuando ya sabés **sobre qué** querés repetir (una lista, un texto, un rango de números), el `for` es
más corto y no se puede colgar:

```python
for fruta in ["manzana", "pera", "uva"]:
    print(fruta)
```

Se lee: *"para cada fruta en esa lista, mostrala"*. No hay contador que actualizar ni condición que
se te olvide: se termina solo cuando no quedan elementos.

### `range()`: para contar

```python
for i in range(5):        # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 6):     # 1, 2, 3, 4, 5
    print(i)

for i in range(0, 10, 2): # 0, 2, 4, 6, 8
    print(i)
```

`range` **arranca en 0** si no le decís otra cosa, y **nunca llega al número final**. Eso último
sorprende al principio, pero es lo que hace que `range(len(lista))` dé exactamente las posiciones
válidas.

:::tip[¿Cuál uso?]
- ¿Sabés de antemano cuántas vueltas son, o tenés una lista? → **`for`**
- ¿Depende de algo que pasa adentro y no sabés cuándo va a terminar? → **`while`**

En la práctica el `for` cubre la gran mayoría de los casos.
:::

## Acumuladores: el patrón que más vas a usar

Sumar todos los números de una lista es siempre la misma receta:

```python
total = 0                  # 1. arrancar en un valor neutro
for numero in [10, 20, 30]:
    total = total + numero # 2. actualizar en cada vuelta
print(total)               # 3. usar el resultado al final  → 60
```

Ese `total` se llama **acumulador**. La misma idea sirve para contar cosas (arrancás en 0 y sumás 1),
o para armar un texto (arrancás en `""` y vas pegando).

## `break` y `continue`

Dos atajos para cuando el bucle tiene que cortarse antes:

```python
for numero in [1, 5, 8, 3]:
    if numero == 8:
        break        # corta el bucle acá, no sigue
    print(numero)    # 1, 5

for numero in [1, 2, 3, 4]:
    if numero % 2 == 0:
        continue     # saltea esta vuelta, sigue con la próxima
    print(numero)    # 1, 3
```

- **`break`** → me voy del bucle.
- **`continue`** → esta vuelta no me interesa, seguí con la siguiente.
