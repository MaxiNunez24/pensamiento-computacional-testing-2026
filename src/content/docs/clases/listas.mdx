## El problema

Querés guardar las notas de un curso. Con variables sueltas sería:

```python
nota1 = 8
nota2 = 10
nota3 = 6
# ...¿y si son 30 alumnos? ¿nota30?
```

Imposible de manejar. Necesitás **una sola variable que guarde muchos valores** y los puedas recorrer
de a uno. Para eso están las **listas**.

## El concepto

Una lista es una **colección ordenada** de valores, entre corchetes y separados por coma:

```python
notas = [8, 10, 6, 9]

print(notas[0])      # 8   (el primero: la posición arranca en 0)
print(len(notas))    # 4   (cuántos elementos tiene)
notas.append(7)      # agrega 7 al final  -> [8, 10, 6, 9, 7]
```

Dos cosas que vas a usar todo el tiempo:

- **Índice**: `notas[0]` es el primero, `notas[-1]` el último.
- **`len(lista)`**: la cantidad de elementos.

:::note[¿Y para recorrerla entera?]
Seguro se te ocurrió: "¿tengo que escribir `notas[0]`, `notas[1]`, `notas[2]`… una por una?". No — se
recorre con un `for`, y es **justo la clase que sigue**. Por ahora quedate con cómo se arma una lista
y cómo se llega a un elemento; recorrerla viene enseguida.
:::

:::caution[La posición arranca en 0]
El primer elemento es `lista[0]`, no `lista[1]`. Si una lista tiene 4 elementos, el último es
`lista[3]` (o `lista[-1]`).
:::

:::note[Cambiar uno que ya está]
`append` agrega al final. Pero muchas veces lo que hace falta es **reemplazar** el que ya está en
una posición, y eso se hace con el índice del lado izquierdo del `=`:

```python
estados = ["P", "P", "A"]
estados[2] = "J"     # el tercero pasa a justificado
print(estados)       # ['P', 'P', 'J']
```

Es lo que hace un sistema de asistencias cada vez que alguien corrige una marca.
:::

## Para llevar

- Lista: `[a, b, c]` — colección ordenada, índice desde `0`.
- `lista[i]`, `lista[-1]`, `len(lista)`, `lista.append(x)`.
- `lista[i] = x` **reemplaza** el que estaba en esa posición.
- `otra = lista` **no copia**: son dos nombres de la misma lista. Para copiar, `lista.copy()`.
- `sorted(lista)` devuelve una **nueva** ordenada; `lista.sort()` **modifica** la original.
- Para recorrerla entera se usa `for`, que es la clase que sigue.

:::note[📦 Tres funciones que ya vienen con Python]
No hace falta recorrer la lista para sacar estas tres: Python ya las trae.

| Función | Qué devuelve | Ejemplo |
|---------|--------------|---------|
| `min(lista)` | el valor más chico | `min([4, 8, 6])` → `4` |
| `max(lista)` | el valor más grande | `max([4, 8, 6])` → `8` |
| `sum(lista)` | la suma de todos | `sum([4, 8, 6])` → `18` |
:::

## 📐 Que las columnas queden derechas

Con las notas guardadas en una lista, lo que sigue siempre es lo mismo: **mostrarlas como una
planilla**. Y una planilla se lee o no se lee según estén las columnas.

Dentro de una f-string, después de los dos puntos se dice **cuánto ocupa** un valor y **hacia dónde
se pega**:

| Se escribe | Qué hace |
|---|---|
| `f"{nombre:<14}"` | ocupa 14 lugares, pegado a la **izquierda** |
| `f"{nota:>6}"` | ocupa 6 lugares, pegado a la **derecha** |
| `f"{nota:.2f}"` | siempre con **2 decimales** — `10` sale `10.00` |
| `f"{nota:>6.2f}"` | las dos cosas juntas |
