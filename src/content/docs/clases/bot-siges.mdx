## El problema

Hoy, para inscribir a alguien en el SiGeS, una preceptora abre la planilla que dejó el formulario
de inscripción, copia el DNI, lo pega en el sistema del Ministerio y completa **unos veinte campos
a mano**, leyendo de la planilla. Después guarda, y vuelve a empezar con el siguiente.

Con treinta inscriptos son un par de horas. Y cada campo es una oportunidad de equivocarse.

Un **bot** hace eso solo: abre el navegador, escribe, hace clic, guarda. Lo mismo que haría una
persona con el mouse, pero sin cansarse.

Ahora, antes de seguir, pensá esto:

## El entorno virtual

Hasta ahora todo lo que usamos venía con Python: `print`, `input`, `csv`. Hoy necesitamos algo que
**no viene**: Playwright, la librería que maneja el navegador. Hay que instalarla.

Y acá aparece un problema que tiene todo el que programa: si instalás todo en el Python de la
compu, el día que dos proyectos necesiten versiones distintas de la misma librería, se pisan. Y el
proyecto que te anda a vos no le anda a tu compañero.

La solución es un **entorno virtual**: una carpeta `.venv` adentro del proyecto, con **su propio
Python y sus propias librerías**. Lo que instalás ahí adentro no toca nada de afuera.

En la terminal de VS Code:

```bash
python -m venv .venv
```

Aparece una carpeta nueva, `.venv`. Ahora hay que **activarlo**, para que la terminal use ese
Python y no el de la compu:

```bash
.venv\Scripts\activate
```

Te das cuenta de que funcionó porque la línea de la terminal empieza con **`(.venv)`**:

```text
(.venv) C:\Users\alumno\Descargas\bot-siges>
```

:::caution[Si dice que "la ejecución de scripts está deshabilitada"]
Es PowerShell, que por seguridad no deja correr el archivo de activación. No hace falta cambiar
nada de la compu: en la terminal, tocá la flechita al lado del **+** y elegí **Command Prompt**.
Ahí `.venv\Scripts\activate` anda sin problema.
:::

:::tip[VS Code también lo puede hacer solo]
`Ctrl+Shift+P` → **Python: Create Environment** → **Venv**. Te crea la carpeta, te pregunta si
querés instalar lo que dice `requirements.txt`, y las terminales nuevas ya se abren activadas.
:::

## Leer la planilla

El formulario de inscripción deja una **planilla**. Bajada como archivo, es un **CSV**: texto, con
una fila por línea y los datos separados por comas. La primera línea son los títulos:

```text
dni,apellidos,nombres,fecha_nacimiento,celular,nacionalidad,domicilio
40000004,Paz,Mateo Ariel,3/12/2004,2215550004,Argentino,Calle 47 nro 629
```

Python trae un módulo para leerlo, `csv`. Y lo más cómodo que tiene es `csv.DictReader`: te da
**cada fila como un diccionario**, con los títulos como claves.

```python
import csv

with open("inscriptos.csv", encoding="utf-8") as archivo:
    for fila in csv.DictReader(archivo):
        print(fila["apellidos"], fila["dni"])
```

La primera línea no aparece como una fila más: `DictReader` la usa para saber cómo se llama cada
columna. Por eso después podés pedir `fila["apellidos"]` en vez de acordarte de que era la
columna 2.

✅ LISTOS PARA CARGAR: 5
     40000004  Paz, Mateo Ariel
     40000001  Gómez, Lucía Belén
     40000005  HERRERA, Sofia Beatriz
     40000003  Ríos, Valentina Rocío

     40000011  Soto, Daniela Aylén

Los mensajes van a ser los tuyos, así que pueden no ser iguales. Lo que tiene que coincidir son
los números: **5 listos y 3 frenados**.

Y ahora, con el navegador:

```bash
python bot.py --lento
```

Se abre el simulador y **se llena solo**, campo por campo. Los tres frenados no se tocan.

:::caution[Si no se abre el navegador]
Si dice que todavía no está instalado Playwright, es que el segundo comando no terminó de bajar el
navegador. Mientras tanto, `--solo-control` anda igual: el control es Python puro y no lo necesita.
Si en tu compu no hay forma de instalarlo, trabajá en pareja con quien sí pudo.
:::

El miércoles, junto con preceptoría, corremos el bot contra el **SiGeS de verdad**, con un alumno
real. Con tres reglas que no se rompen:

1. **Primero el simulador.** Hasta que no anda perfecto acá, no toca el sistema real.
2. **No se loguea solo.** No tiene usuario ni contraseña: una persona entra al sistema y recién
   ahí el bot toma el control.
3. **No genera la matrícula.** Deja al alumno como **pre inscripto**, que tiene un tachito al lado
   para borrarlo si algo salió mal. La matrícula la genera una persona, mirando.

## Para llevar

- Un **bot no arregla un proceso malo: lo acelera.** Primero se controla, después se carga.
- `csv.DictReader` te da cada fila de una planilla como un **diccionario**.
- De cada fila, **un objeto**: la planilla trae los datos y la clase les da comportamiento.
- Un **entorno virtual** (`.venv`) tiene su propio Python y sus librerías. Se sube
  `requirements.txt`, nunca el `.venv`.
- **El bot no decide: tipea.** La decisión está en tu `alumno.py`.
