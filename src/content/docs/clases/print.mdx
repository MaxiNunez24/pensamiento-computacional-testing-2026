## El problema

Una computadora puede hacer millones de cuentas por segundo. Pero si no te **muestra** el resultado,
es como si no hubiera hecho nada: el número queda adentro de la máquina y se pierde.

`print()` es la forma de decirle *"esto, mostrámelo"*.

```python
print("Hola mundo")
```

## Comillas: texto vs. otra cosa

Esta es la primera trampa del lenguaje.

```python
print("Hola")    # muestra: Hola
print(Hola)      # 💥 error: NameError
```

Con comillas, `"Hola"` es un **texto** (un *string*). Sin comillas, Python cree que `Hola` es el
**nombre de algo** que vos definiste antes — y como no existe, se queja.

Sirven las comillas dobles `"` o simples `'`, mientras abras y cierres con la misma.

## Mostrar varias cosas juntas

`print()` acepta varias cosas separadas por **comas**, y las muestra con un espacio en el medio:

```python
print("Tengo", 30, "años")   # Tengo 30 años
```

Fijate que `30` va **sin comillas**: es un número, no un texto. `print()` se banca ambos.

:::caution[La coma no es lo mismo que el `+`]
```python
print("Tengo", 30)     # ✅ Tengo 30
print("Tengo" + 30)    # 💥 TypeError: no podés sumar texto con número
```
La coma **junta cosas para mostrarlas**. El `+` intenta **sumarlas**, y sumar un texto con un número
no significa nada.
:::

## f-strings: meter valores adentro del texto

Cuando el texto y los datos se mezclan mucho, las comas se vuelven incómodas. Para eso están las
**f-strings**: una `f` antes de la comilla, y las variables entre llaves `{}`.

```python
nombre = "Ana"
edad = 30

print(f"{nombre} tiene {edad} años")   # Ana tiene 30 años
```

Se lee de corrido, que es justamente la gracia.

:::note[Si te olvidás la `f`]
```python
print("{nombre} tiene {edad} años")   # {nombre} tiene {edad} años
```
Sin la `f`, las llaves son texto común y salen tal cual. Es un error silencioso: no rompe, solo
muestra cualquier cosa. Si ves llaves en tu salida, fijate la `f`.
:::

## Saltos de línea

Cada `print()` termina con un salto de línea. Si querés uno en el medio, usás `\n`:

```python
print("Primera línea\nSegunda línea")
```

Y si NO querés el salto al final, `end=""`:

```python
print("Hola, ", end="")
print("mundo")            # Hola, mundo  (en una sola línea)
```

## Los tres errores que vas a cometer

| Error | Qué pasó |
|-------|----------|
| `NameError: name 'Hola' is not defined` | Te faltaron las comillas: Python creyó que era el nombre de algo. |
| `SyntaxError: unterminated string literal` | Abriste una comilla y no la cerraste. |
| `TypeError: can only concatenate str` | Usaste `+` entre texto y número. Probá con coma o f-string. |

:::tip[Leé el error de abajo para arriba]
Python te dice **el tipo de error** en la última línea y **en qué línea** de tu código pasó. Con esas
dos cosas ya sabés dónde mirar. No hace falta entender todo el bloque.
:::
