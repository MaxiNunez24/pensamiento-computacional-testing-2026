## Dos molestias que vamos a resolver

Las dos aparecieron solas apenas el `Alumno` de POO I entró al sistema:

1. **Los objetos se imprimen feo:** `print(ana)` muestra `<__main__.Alumno object at 0x...>` 😵. En
   una lista de veinte alumnos eso es ilegible.
2. **Cualquiera rompe los datos:** `ana.marcas.append("Z")` mete un estado que no existe. Ese día
   deja de contar, el porcentaje del año da mal, y nadie se entera hasta que la planilla no cierra.

## `__str__`: que el objeto se imprima lindo

`__str__` es un **método especial** (*dunder*): Python lo llama solo cuando hacés `print(obj)` o
`str(obj)`. Vos definís qué texto devuelve.

```python
class Alumno:
    def __init__(self, dni, apellido, nombre):
        self.dni = dni
        self.apellido = apellido
        self.nombre = nombre
    def __str__(self):
        return f"{self.dni} — {self.apellido}, {self.nombre}"

print(Alumno("30111222", "Perez", "Ana"))   # 30111222 — Perez, Ana
```

## Encapsulamiento: que los datos no acepten cualquier cosa

**Encapsular** es esconder los datos internos y obligar a tocarlos **solo por métodos controlados**
(como un cajero: usás los botones, no metés la mano en la caja fuerte). En Python, un atributo que
arranca con **`_`** señala *"esto es interno, no lo toques de afuera"*.

```python
class Asistencia:
    def __init__(self, fecha):
        self.fecha = fecha
        self._estado = "A"             # interno: solo se cambia por marcar()
    def marcar(self, estado):
        if estado in ("P", "A", "T", "J"):
            self._estado = estado
```

Fijate lo que gana el sistema: **no existe forma de que una marca sea `"Z"`**. No hace falta
revisarlo después en la pantalla, ni en el archivo, ni en el reporte. Se controla en un solo lugar.

En un diagrama, `-` es privado y `+` es público:

La clase entera, junta: guarda sus marcas, no acepta las inválidas, calcula su porcentaje y sabe
imprimirse.

- `marcar(estado)` — agrega la marca **solo si es válida**.
- `porcentaje()` — qué porcentaje de los días **vino**. La `"T"` cuenta como que vino (llegó tarde,
  pero estuvo). Sin marcas, `0`.
- `__str__` — devuelve `Apellido, Nombre — <porcentaje>%` con **un decimal**.

:::caution[La decisión que hay atrás]
Que la `T` cuente como presente **no es una cuestión técnica**: es una regla del CFP, y alguien la
tuvo que decidir. Cuando el sistema esté andando, la primera pregunta de preceptoría va a ser
exactamente esta. Tenerla escrita en un método —y no repartida en cinco pantallas— es lo que
permite cambiarla el día que cambie.
:::

## Para llevar

- `__str__` define cómo se imprime tu objeto (hay más *dunder*: `__repr__`, `__len__`, `__eq__`…).
- Encapsular = datos internos con `_` + métodos que controlan el acceso (la "puerta").
- Validar **al entrar** sale más barato que validar en cada lugar donde el dato se usa.
- Una regla del negocio (la `T` cuenta como presente) vive en **un** método, no repartida.
- En el diagrama: `-` privado, `+` público.
