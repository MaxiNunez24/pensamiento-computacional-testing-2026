## La caja de tests

Abrí **🧪 Mis tests** y vas a encontrar el otro lado del mostrador: en vez de que los tests vengan
dados, los escribís vos.

Un test es una **afirmación sobre tu código**. Si es verdadera no pasa nada; si es falsa, salta:

```python
assert 2 + 2 == 4        # no pasa nada: es verdad
assert 2 + 2 == 5        # 💥 salta
```

Adentro de los tests tenés `salida`, que es **todo lo que imprimió tu programa**:

```python
assert salida.strip() == "Hola"
```

Y si tu código define funciones, las podés llamar directamente:

```python
assert sumar(2, 3) == 5
assert sumar(-1, 1) == 0
```

:::tip[Cuando algo no coincide, mirá la explicación]
Si un `assert` de igualdad falla, abajo te dice **qué difiere**: si son el mismo texto salvo por los
acentos, si cambian las mayúsculas, si sobra un espacio, o en qué caracter exacto se separan.
:::

:::note[Esto es testing, y lo vamos a ver en serio más adelante]
Escribir tests es la mitad del oficio: no alcanza con que tu programa ande *con el caso que probaste*.
Un buen test es el que **atrapa el error que todavía no sabés que tenés** — por ejemplo, ¿tu función
anda con la lista vacía? ¿Con un número negativo? ¿Con cero?

Por ahora, usá esta caja para acostumbrarte a preguntarte *"¿cómo sé que esto está bien?"*.
:::

## Las entradas

Si tu código usa `input()`, cargá los valores en la caja de **⌨️ Entradas**, uno por línea. El
programa los va tomando en orden, como si alguien los estuviera tecleando.

Dejala vacía si no usás `input()`.

:::caution[Ojo con `salida` cuando usás `input()`]
Para que se parezca a una terminal de verdad, cada `input()` **imprime su pregunta seguida de lo que
se “tecleó”**. O sea que eso también queda adentro de `salida`.

Con este programa y la entrada `Guada`:

```python
n = input("Nombre? ")
print("Hola", n)
```

`salida` no es `"Hola Guada"`, es:

```
Nombre? Guada
Hola Guada
```

Así que un test como `assert salida.strip() == "Hola Guada"` **falla**. Si querés mirar solo lo
último que mostró tu programa, usá:

```python
assert salida.strip().splitlines()[-1] == "Hola Guada"
```
:::
