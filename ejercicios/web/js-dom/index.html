JavaScript II · Leer y cambiar la página

Antes de empezar

Usa lo de JavaScript I y los bloques de HTML y CSS. Desde acá los ejercicios tienen HTML y JavaScript: tu programa cambia la página, y la ves cambiar.

El problema

Sección titulada «El problema»

El catálogo dice qué productos hay, pero no cuáles se agotaron. Los precios están escritos a mano en el HTML. Y si mañana agregás un producto, hay que copiar y pegar una tarjeta entera. Todo eso lo puede hacer un programa: leer la página, cambiarla y agregarle cosas.

El DOM: la página como objetos

Sección titulada «El DOM: la página como objetos»

Cuando el navegador lee tu HTML, arma en memoria un árbol de objetos, uno por cada etiqueta. Ese árbol se llama DOM (Document Object Model), y JavaScript lo puede leer y cambiar. Cada cambio se ve al instante en la página.

Todo arranca de document, que es la página entera.

Armar pedazos de HTML de una
Sección titulada «Armar pedazos de HTML de una»


Para algo más grande que un <li> —una tarjeta con título, precio y botón—, crear cada elemento por
separado es largo. Se puede escribir el HTML entero en una template string y meterlo con
innerHTML:




Es exactamente lo que hiciste con el f-string de Python en el catálogo: un texto con huecos para
los datos.


innerHTML, solo con datos tuyos
innerHTML interpreta el texto como HTML. Si el texto viene de alguien de afuera —lo que
escribió una persona en un formulario—, puede meter un <script> y correr su programa en tu página.
Para mostrar lo que escribe la gente, textContent, que lo muestra tal cual, sin interpretarlo.

Para llevar
Sección titulada «Para llevar»


    

  • El DOM es la página como un árbol de objetos. Arranca en document.
    • 

  • document.querySelector(selector) → el primero (o null); querySelectorAll → todos.
Los mismos selectores de CSS.
    • 

  • .textContent lee y cambia el texto.
    • 

  • .classList.add / remove / toggle: el CSS define la clase, JavaScript la pone o la saca.
    • 

  • data-algo en el HTML se lee con .dataset.algo, y siempre es texto.
    • 

  • Crear: document.createElement("li"), completarlo, y .append() adentro de otro.
    • 

  • innerHTML con una template string arma HTML de una, pero solo con datos tuyos. Lo que escribe
la gente, con textContent.
