JavaScript I · Para quien ya sabe Python

Antes de empezar

Esta clase da por sabido Python: variables, if, for, funciones, listas y diccionarios. Si eso lo tenés, JavaScript te va a resultar conocido. En estos ejercicios no hay página: lo que importa es la consola, que es el print de JavaScript.

El problema

Sección titulada «El problema»

Con HTML y CSS la página se ve, pero no hace nada: tocás un botón y no pasa nada. Para que responda hace falta un programa, y el único lenguaje que entienden todos los navegadores es JavaScript.

La buena noticia: ya sabés programar. Las ideas son las mismas —variables, condiciones, bucles, funciones, listas—; lo que cambia es cómo se escriben. Esta clase es una traducción.

La gran diferencia: llaves en vez de sangría

Sección titulada «La gran diferencia: llaves en vez de sangría»

En Python, lo que está adentro de un if o un def lo marca la sangría. En JavaScript, lo marcan las llaves { }, y la condición va entre paréntesis:

  • 🐍 Python
  • ⚡ JavaScript

La sangría en JavaScript se usa igual, para que se lea bien, pero al lenguaje le da lo mismo: mandan las llaves. Y cada instrucción termina con punto y coma: no siempre es obligatorio, pero se pone.

El ===, y por qué no ==
Sección titulada «El ===, y por qué no ==»


JavaScript tiene dos formas de comparar, y una es una trampa:




== trata de convertir antes de comparar, y da resultados que nadie espera (0 == "" es
true). === compara de verdad, como el == de Python. Usá siempre === (y !== para
“distinto”).

Listas y bucles
Sección titulada «Listas y bucles»


Una lista de Python es un array en JavaScript. Se escribe igual, con corchetes, y se recorre con
un for ... of:

 
 
     
  •    🐍 Python  
  •    ⚡ JavaScript  
    •  
 
 
 
 
 
 
    

of, no in
JavaScript también tiene for (const x in lista), y no hace lo que esperás: recorre las
posiciones ("0", "1", "2"), no los elementos. El que equivale al for de Python es
for ... of.

Para llevar
Sección titulada «Para llevar»


    

  • Llaves en vez de sangría, condiciones entre paréntesis, ; al final.
    • 

  • console.log es el print. let para lo que cambia, const para lo que no.
    • 

  • === siempre, nunca ==. true, false, null en minúscula. &&, ||, !.
    • 

  • Template strings: `Hola, ${nombre}`, con comillas invertidas.
    • 

  • function nombre(params) { return ...; }, y los nombres en camelCase.
    • 

  • Arrays: [1, 2], .push(), .length, y se recorren con for (const x of lista).
    • 

  • Objetos: { clave: valor }, y se lee con objeto.clave.
