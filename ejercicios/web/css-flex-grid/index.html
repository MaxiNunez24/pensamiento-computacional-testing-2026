CSS III · Flexbox y Grid

Antes de empezar

Usa lo de CSS II: el modelo de caja y display.

El problema

Sección titulada «El problema»

Las cajas en bloque van una abajo de la otra. Siempre. Pero casi todo lo que querés hacer en una página va al lado: el menú en una fila, el logo a la izquierda y los links a la derecha, las tarjetas del catálogo en una grilla de tres.

Durante años eso se hacía con trucos que se rompían solos. Hoy hay dos herramientas hechas para esto, y son de lo mejor que tiene CSS:

Para…
FlexboxCosas en una fila (o en una columna): un menú, una cabecera, botones
GridUna grilla de filas y columnas: el catálogo, una galería

Flexbox: en una fila

Sección titulada «Flexbox: en una fila»

La idea clave: el estilo se le pone al CONTENEDOR, no a cada cosa. El contenedor dice “mis hijos van en fila”, y ellos se acomodan.

Con solo eso, los links del menú pasan a estar en fila. gap es el espacio entre los hijos (no en los bordes): mucho más cómodo que ponerle margen a cada uno.

Repartir el espacio y alinear
Sección titulada «Repartir el espacio y alinear»


Con los hijos en fila, dos propiedades del contenedor deciden dónde quedan:






















PropiedadSobre…Valores que más se usan
justify-contentA lo largo de la fila (horizontal)flex-start, center, flex-end, space-between
align-itemsA lo ancho (vertical)stretch, center, flex-start


space-between deja el primero contra un borde, el último contra el otro, y reparte lo que
sobra entre ellos: es la cabecera de casi todas las páginas, con el logo a la izquierda y el menú a
la derecha. Y align-items: center los centra verticalmente, que antes de Flexbox era
famosamente difícil.

 ⭐ Fundamental ✓ Resuelto

alto (el logo es más grande, y sin esto quedan desparejos).

Grid: la grilla
Sección titulada «Grid: la grilla»


Flexbox piensa en una fila. Para filas y columnas a la vez, Grid. También va en el
contenedor:




fr es una fracción del espacio que sobra: 1fr 1fr 1fr son tres partes iguales. 2fr 1fr
sería una columna el doble de ancha que la otra. Y como repetir es aburrido:
repeat(3, 1fr) es lo mismo.


Los hijos van llenando la grilla en orden, de izquierda a derecha y de arriba hacia abajo. Seis
tarjetas en tres columnas: dos filas, solas.


 
 🌱 
La grilla de tres
 ⭐ Fundamental ✓ Resuelto 
 
 
Armá la grilla del catálogo: 3 columnas iguales con 16px de separación.

.producto h2 { margin: 0 0 4px; font-size: 1.1rem; }
.producto p { margin: 0; color: #2f4858; font-weight: bold; }

Que se acomode sola
Sección titulada «Que se acomode sola»


Tres columnas quedan bien en la compu, pero en un celular cada tarjeta mediría 100 píxeles. Lo
ideal sería: “poné tantas columnas como entren, de por lo menos 150px cada una”. Y eso se puede
escribir casi así:





















PedazoQuiere decir
repeat(auto-fill, ...)Tantas columnas como entren
minmax(150px, 1fr)Cada una, de 150 como mínimo; si sobra, se estiran en partes iguales


En un celular entran dos; en una compu, cinco o seis. Sin una sola línea más. Es exactamente la
grilla del catálogo de la clase Tu catálogo con Python.


 
 🌿 
La grilla que se acomoda sola
  ✓ Resuelto 
 
 
La grilla tiene siempre 3 columnas, y en un celular quedan apretadas. Cambiala para que ponga
tantas columnas como entren, de 150px como mínimo. Achicá y agrandá la ventana para verla
acomodarse.
 
  
 🎨 Los estilos que ya vienen hechos (CSS) 
* { box-sizing: border-box; }
body { margin: 0; padding: 16px; font-family: system-ui, sans-serif; background: #faf7f2; }
.producto { padding: 12px; border-radius: 10px; background: white; box-shadow: 0 1px 4px rgb(0 0 0 / 0.1); }
.producto h2 { margin: 0 0 4px; font-size: 1.1rem; }
.producto p { margin: 0; color: #2f4858; font-weight: bold; }

Para llevar
Sección titulada «Para llevar»


    

  • El estilo va en el contenedor: él dice cómo se acomodan sus hijos.
    • 

  • Flexbox: display: flex pone los hijos en fila. gap los separa. justify-content
reparte a lo largo (space-between: uno a cada borde); align-items: center los centra de alto.
    • 

  • Grid: display: grid y grid-template-columns. fr es una fracción de lo que sobra:
repeat(3, 1fr) son tres columnas iguales.
    • 

  • repeat(auto-fill, minmax(150px, 1fr)): tantas columnas como entren, de 150 como mínimo. La
grilla que se acomoda sola.
    • 

  • Una fila → Flexbox. Filas y columnas → Grid.
