🧩 Cómo se planifica un sistema

Hoy la asistencia del CFP se toma en papel y se pasa a mano a varias planillas. Estamos haciendo un Sistema de Gestión de Alumnos para que se cargue una sola vez. Antes de programar, lo planificamos: así se va a ver.

  1. Entender el problema. Entrevistamos a quienes toman asistencia y arman las planillas.
  2. Dibujar cómo va a funcionar. Quién carga qué, desde dónde, y qué sale solo.
  3. Partirlo en pedazos. Cada clase, una parte: los alumnos, la asistencia, la base de datos.
  4. Programarlo y probarlo. Con tests que avisan si algo se rompe.
