🎁 Tres recursos de midudev

Sección titulada «🎁 Tres recursos de midudev»

Los tres los hizo Miguel Ángel Durán, midudev, que comparte gratis una cantidad enorme de material para aprender a programar en castellano. Gracias.

aprendesql.dev — aprender SQL Veintitantas lecciones en castellano, del primer SELECT a las subconsultas, con un editor de SQL en cada lección. Es lo que conviene usar para practicar las consultas del sistema de asistencias.
alg0.dev — los algoritmos, animados Casi cincuenta algoritmos que se ejecutan paso a paso delante tuyo, con código en Python. Lo que en Eficiencia medimos, acá se ve moverse.
itsfree.dev — servicios con plan gratis Hosting, bases de datos, envío de mails: un catálogo de servicios con un plan gratis de verdad. Para el día que quieras publicar un proyecto propio.
