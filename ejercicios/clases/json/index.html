← Volver a la teoría de esta clase

El problema

Sección titulada «El problema»

Con archivos de texto ya sabés guardar cosas. Probemos con un diccionario:

El archivo queda con {'nombre': 'Guada', 'edad': 25}. Parece que funcionó… hasta que lo querés leer de vuelta:

Lo que recuperaste es un texto que se parece a un diccionario, no un diccionario. Perdiste la estructura: los números son texto, no podés acceder por clave, nada.

JSON resuelve exactamente eso: guardar estructuras enteras y recuperarlas tal como estaban.

Qué es JSON

Sección titulada «Qué es JSON»

Un formato de texto para representar datos, que todos los lenguajes entienden. Un programa en Python guarda un JSON y otro en JavaScript lo lee sin problema. Por eso es la forma en que viaja casi toda la información por internet.

Se parece muchísimo a un diccionario de Python, y no es casualidad.

PythonJSON
dictobjeto {}
listarreglo []
strstring (siempre comillas dobles)
int / floatnumber
True / Falsetrue / false
Nonenull

Las diferencias que te van a morder

  • En JSON las comillas son siempre dobles: "nombre", nunca 'nombre'.
  • Se escribe true / false / null en minúscula, no True / False / None.
  • No se permite coma al final del último elemento.

Por eso no alcanza con copiar un diccionario de Python y decir que es JSON: hay que convertirlo.

Las cuatro funciones

Sección titulada «Las cuatro funciones»

El módulo json tiene cuatro, y la diferencia está en si trabajan con archivos o con textos:

De Python a JSONDe JSON a Python
con un archivojson.dump(datos, archivo)json.load(archivo)
con un stringjson.dumps(datos)json.loads(texto)

La s final significa string. Las que más vas a usar son dump y load, las de archivo.

Los dos parámetros que conviene poner siempre

  • ensure_ascii=False → si no, las tildes y la ñ se guardan como \u00f1 y el archivo queda ilegible para un humano. Los datos están bien igual, pero no podés abrirlo y entenderlo.
  • indent=2 → guarda el JSON con saltos de línea y sangría, en vez de todo apretado en un renglón. Sin esto, un archivo de 50 alumnos es una sola línea infinita.

Cuándo JSON y cuándo texto plano
Sección titulada «Cuándo JSON y cuándo texto plano»



















Texto plano (.txt)Un log, una lista simple de líneas, algo que va a leer una persona
JSON (.json)Estructuras: diccionarios, listas anidadas, datos que otro programa va a volver a cargar


Regla práctica: si lo que guardás no es una lista de líneas sueltas, es JSON.
