Taller: el sistema por consola

Hoy sale la primera versión que anda

Todo lo que vimos hasta acá eran piezas: el Alumno de POO, el raise de Excepciones, el repositorio de SQLite. Hoy se juntan en un programa que se usa: das de alta a un alumno, le pasás lista, cerrás, y mañana los datos siguen ahí.

Cómo está armado

Sección titulada «Cómo está armado»

El sistema son tres archivos, y cada uno tiene un solo trabajo:

La regla de oro

Sección titulada «La regla de oro»

En menu.py solo hay input(), print() y llamadas a funciones de repositorio.py. Ni una línea de SQL, ni una regla.

Parece una manía, pero es lo que más trabajo nos va a ahorrar en el curso. En unas semanas el sistema pasa a la web, con Flask: en vez de input() va a haber un formulario, y en vez de print(), una página. Eso es exactamente lo que hace menu.py. Si todo lo demás está en los otros dos archivos, pasar a la web es cambiar un archivo solo. Si el SQL está desparramado por el menú, es reescribir el sistema.

    Una tabla nueva: las marcas

    Sección titulada «Una tabla nueva: las marcas»

    Los alumnos ya tienen su tabla. Falta dónde anotar quién vino cada día:

    Una fila por alumno y por día: ('2026-10-02', '30111222', 'P'). El estado es P (presente), A (ausente) o T (tarde), y los tres están en ESTADOS, en repositorio.py.

    ¿Por qué la fecha va al revés?

    2026-10-02 y no 02/10/2026: así, ordenadas como texto, las fechas quedan en orden. Con el formato de siempre, el 02/11 quedaría antes que el 15/10.

    Y una regla que salió de preceptoría: las marcas se corrigen. Si alguien marcó presente al que llegó tarde, se cambia. Pero tiene que quedar una sola marca por alumno y por día.

    🌿

    """La clase Alumno: la de POO, con lo que le agregamos en Excepciones.

Un Alumno con el DNI roto no llega a existir: el __init__ levanta ValueError,
y quien lo quiso crear decide qué hacer (en el menú: avisarle a la persona).
"""


class Alumno:
    def __init__(self, dni, apellido, nombre, activo=True):
        dni = dni.strip()
        if not dni.isdigit() or len(dni) not in (7, 8):
            raise ValueError("el DNI tiene que ser de 7 u 8 números, sin puntos")
        if not apellido.strip() or not nombre.strip():
            raise ValueError("faltan el apellido o el nombre")
        self.dni = dni
        self.apellido = apellido.strip()
        self.nombre = nombre.strip()
        self.activo = activo

    def nombre_completo(self):
        return f"{self.apellido}, {self.nombre}"

    def __str__(self):
        return f"{self.nombre_completo()} (DNI {self.dni})"

    """Todo lo que toca la base vive acá. Ningún otro archivo escribe SQL.

El resto del sistema pide un Alumno y recibe un Alumno: de las filas y las
tablas no se entera nadie más. Por eso, cuando el sistema pase a Flask, este
archivo se usa tal cual, sin cambiarle una línea.
"""
import sqlite3

from alumno import Alumno

# Los estados posibles de una marca: presente, ausente, tarde.
ESTADOS = ("P", "A", "T")


def conectar(archivo="asistencias.db"):
    """Abre la base (si no existe, la crea) y se asegura de que estén las tablas."""
    con = sqlite3.connect(archivo)
    crear_tablas(con)
    return con


def crear_tablas(con):
    con.execute(
        "CREATE TABLE IF NOT EXISTS alumnos "
        "(dni TEXT PRIMARY KEY, apellido TEXT, nombre TEXT, activo INTEGER DEFAULT 1)"
    )
    # Una fila por alumno y por día. La fecha va como texto "2026-10-02": así,
    # ordenada alfabéticamente, también queda ordenada por fecha.
    con.execute("CREATE TABLE IF NOT EXISTS marcas (fecha TEXT, dni TEXT, estado TEXT)")
    con.commit()


def guardar_alumno(con, alumno):
    """Agrega un Alumno a la base. Devuelve False si ese DNI ya estaba."""
    try:
        con.execute(
            "INSERT INTO alumnos (dni, apellido, nombre) VALUES (?, ?, ?)",
            (alumno.dni, alumno.apellido, alumno.nombre),
        )
    except sqlite3.IntegrityError:
        return False
    con.commit()
    return True


def buscar_alumno(con, dni):
    """El Alumno con ese DNI, o None si no está."""
    fila = con.execute(
        "SELECT dni, apellido, nombre, activo FROM alumnos WHERE dni = ?", (dni,)
    ).fetchone()
    if fila is None:
        return None
    return Alumno(fila[0], fila[1], fila[2], fila[3] == 1)


def listar_alumnos(con):
    """Los alumnos activos, ordenados por apellido."""
    filas = con.execute(
        "SELECT dni, apellido, nombre FROM alumnos WHERE activo = 1 ORDER BY apellido, nombre"
    ).fetchall()
    return [Alumno(f[0], f[1], f[2]) for f in filas]

    El menú
    Sección titulada «El menú»
    

    El menú es un while True que muestra las opciones, pregunta, y llama a la función que
corresponde. Solo se corta cuando eligen salir. Ya lo hiciste con el cajero automático, en la
clase de bucles: es lo mismo, con otras opciones.
    

     
     🌿 
    El menú que no se cierra solo
     ⭐ Fundamental ✓ Resuelto  
     
     
    Hacé que el menú se repita hasta que elijan 5, y que cada opción llame a su función:
    





























    OpciónLlama a
    1opcion_ver(con)
    2opcion_alta(con)
    3opcion_pasar_lista(con, hoy)
    4opcion_lista_de_hoy(con, hoy)
    5nada: dice ¡Hasta luego! y termina
    Con cualquier otra cosa, Opción inválida, y el menú vuelve a aparecer. Las opciones ya están
hechas (acá solo avisan que las llamaste), y en ⌨️ Entradas podés cambiar lo que se elige.

        "(dni TEXT PRIMARY KEY, apellido TEXT, nombre TEXT, activo INTEGER DEFAULT 1)"
    )
    # Una fila por alumno y por día. La fecha va como texto "2026-10-02": así,
    # ordenada alfabéticamente, también queda ordenada por fecha.
    con.execute("CREATE TABLE IF NOT EXISTS marcas (fecha TEXT, dni TEXT, estado TEXT)")
    con.commit()


def guardar_alumno(con, alumno):
    """Agrega un Alumno a la base. Devuelve False si ese DNI ya estaba."""
    try:
        con.execute(
            "INSERT INTO alumnos (dni, apellido, nombre) VALUES (?, ?, ?)",
            (alumno.dni, alumno.apellido, alumno.nombre),
        )
    except sqlite3.IntegrityError:
        return False
    con.commit()
    return True


def buscar_alumno(con, dni):
    """El Alumno con ese DNI, o None si no está."""
    fila = con.execute(
        "SELECT dni, apellido, nombre, activo FROM alumnos WHERE dni = ?", (dni,)
    ).fetchone()
    if fila is None:
        return None
    return Alumno(fila[0], fila[1], fila[2], fila[3] == 1)


def listar_alumnos(con):
    """Los alumnos activos, ordenados por apellido."""
    filas = con.execute(
        "SELECT dni, apellido, nombre FROM alumnos WHERE activo = 1 ORDER BY apellido, nombre"
    ).fetchall()
    return [Alumno(f[0], f[1], f[2]) for f in filas]
