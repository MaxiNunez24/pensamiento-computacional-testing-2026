Funciones I — definición, parámetros y retorno

← Volver a la teoría de esta clase

Antes de empezar

Esta clase es interactiva. Escribí el código en cada recuadro, tocá ▶ Ejecutar para verlo correr y ✓ Verificar para que los tests te digan si está bien. La primera vez tarda unos segundos en cargar Python. 🐍

El problema

Sección titulada «El problema»

Tenés que saludar a tres personas:

Funciona… pero si mañana el saludo cambia a “¡Buenas, Ana!”, tenés que tocar las tres líneas. Y si fueran 100 personas, 100 líneas. Estás repitiendo la misma idea una y otra vez.

¿Y si pudieras guardar la idea de “saludar” en un solo lugar, ponerle nombre, y reusarla las veces que quieras? Para eso existen las funciones.

Qué es una función

Sección titulada «Qué es una función»

Una función es un bloque de código con nombre que podés ejecutar (llamar) cuando quieras. Recibe datos de entrada (parámetros) y puede devolver un resultado (retorno).

Tres piezas clave:

  • def + nombre + (parámetros) → así se define.
  • return → el valor que la función devuelve a quien la llamó.
  • Llamarla: saludar("Ana") ejecuta el bloque con nombre = "Ana".

return no es print

print muestra algo en pantalla; return devuelve un valor para seguir usándolo. Una función que solo hace print no te sirve para guardar el resultado en una variable.

Manos a la obra

Sección titulada «Manos a la obra»

Vas a ver pass en el código

pass es un marcador de lugar: una línea que no hace nada. Está para que el código sea válido mientras todavía no lo escribiste. Borralo y poné tu solución en su lugar.

 🌿 
La mayúscula que no era
 ✓ Resuelto 
 
 
Este programa tendría que decir si una contraseña tiene al menos una mayúscula. Con
"Python123" contesta bien, pero con "python123" también dice True:
Marcá la línea donde está el error.
Este salió de un intento real
No es un error inventado para el ejercicio: es de una solución que se escribió en clase y que
parecía correcta. Falla solo con los casos que uno no prueba — y la contraseña 12345678, que no
tiene una sola letra, pasaba el control de “tiene mayúscula”.
Por eso los tests de acá abajo prueban con números, con espacios y con una sola letra. Los casos
raros no son un capricho: son los únicos que encuentran esta clase de error.

 💡 Pistas 
     
  1. Probá vos mismo en el probador: ¿qué contesta "1".upper() == "1"? ¿Y " ".upper() == " "?
  2. La condición no es falsa: es otra pregunta. Dice “pasarlo a mayúscula lo deja igual”, que no es lo mismo que “es una mayúscula”.
  3. Buscás el método que pregunta en vez del que transforma. En inglés, “es mayúscula”.
