El problema: código repetido

Sección titulada «El problema: código repetido»

Perro y Gato comparten nombre, edad y comer(), y solo cambian el sonido. Escribir todo dos veces es un desperdicio. La herencia te deja escribir lo común una sola vez.

Herencia: heredar para no repetir

Sección titulada «Herencia: heredar para no repetir»

class Perro(Animal) se lee “Perro es un Animal”. Perro no escribió __init__ ni comer(), pero los tiene (los heredó). Si la hija define un método que ya existía, el suyo gana: eso es sobrescribir (override). Y con super().__init__(...) reusás el constructor de la madre cuando la hija necesita un atributo más.
